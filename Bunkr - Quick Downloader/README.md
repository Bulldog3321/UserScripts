# Bunkr - Quick Downloader

One-click file downloads for Bunkr.

## Features
- Adds download buttons to each file in albums.
- Download tabs open in the background.
- On download pages, auto-clicks the download button.

## Installation
[Click here](https://bulldog3321.github.io/UserScripts/Bunkr%20-%20Quick%20Downloader/bunkr-quick-downloader.user.js) — your userscript manager will prompt you to install it.

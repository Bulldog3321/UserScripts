# Spotify - Music Downloader

Download Spotify songs from various third-party providers.

## Features
- Adds download buttons on each track in playlist/album views.
- **Multiple providers**: Uses Lucida, DoubleDouble, SQUID.WTF, and Monochrome for song downloads.

## Installation
[Click here](https://bulldog3321.github.io/UserScripts/Spotify%20-%20Music%20Downloader/spotify-music-downloader.user.js) — your userscript manager will prompt you to install it.

# Linkify Plain-Text URLs

Converts plain-text URLs on any webpage into clickable links.

## Features
- Only applies to real top-level domains to prevent false positives.
- Skips localhost and URLs inside form fields, code blocks, and other safe elements.

[Click here](https://bulldog3321.github.io/UserScripts/Linkify%20Plain-Text%20URLs/linkify-plain-text-urls.user.js) — your userscript manager will prompt you to install it.

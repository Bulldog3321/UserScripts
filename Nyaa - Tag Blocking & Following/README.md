# Nyaa - Tag Blocking & Following

Hide or highlight releases on Nyaa based on tags.

## Features
- **Block tags**: Add tags to the block list to hide matching releases from the torrent list.
- **Follow tags**: Add tags to the follow list to highlight matching releases.
- **Advanced rules**: Create rules with `not if` and `only if` conditions for precise filtering.
- **Tag column**: A toggleable Tag column shows detected tags per release.
- **Click-to-block**: Click any tag in the release name or tag column to block it.

# UserScripts

A collection of userscripts I've made for personal use.

| Script | Description |
|---|---|
| [Linkify Plain Text URLs](Linkify%20Plain-Text%20URLs) | Converts plain-text URLs on any webpage into clickable links. |
| [GitHub - File/Folder/Gist Downloader](GitHub%20-%20File%20Folder%20Gist%20Downloader) | Download files and folders from repositories, download or copy Gists, and a Gist link on user profiles. |
| [Civitai - URL Cleaner](Civitai%20-%20URL%20Cleaner) | Strips unnecessary model names from Civitai URLs and adds quick actions for clearing model versions and swapping between .com and .red domains. |
| [Bunkr - Quick Downloader](Bunkr%20-%20Quick%20Downloader) | One-click file downloads for Bunkr. |
| [Daily Uploads - File Search](Daily%20Uploads%20-%20File%20Search) | Adds filename searching to Daily Uploads user pages. |
| [Turbo.cr - Captcha Bypass](Turbo.cr%20-%20Captcha%20Bypass) | Auto-solves Altcha captchas on Turbo.cr. |

## Usage
1. Install your userscript manager of choice. [Violentmonkey](https://violentmonkey.github.io/) is recommended.
2. Open a script's folder for instructions.

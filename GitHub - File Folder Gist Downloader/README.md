# GitHub - File/Folder/Gist Downloader

Download files and folders from repositories, download or copy Gists, and a Gist link on user profiles.

## Features
- Adds download buttons on each file/folder in a repo. Downloading a folder opens a menu with two third-party download options — [DownGit](https://minhaskamal.github.io/DownGit/) and [download-directory](https://download-directory.github.io/). File downloads are fetched from the Github raw link.
- **Size tooltips**: File/folder size is shown while hovering over download buttons.
- **Gist buttons**: Adds download and copy next to the "Raw" button on Gists.
- **Gist profile link**: Adds a "View Gist Profile" button to user profiles.
